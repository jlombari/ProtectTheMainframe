# Protect The Mainframe!
A python-focused quiz game for beginner students. 

![Game Menu](https://github.com/jlombari/ProtectTheMainframe/blob/main/Screenshot%202026-09-14%20170622.png)

> Originally written as a text-based quiz game.

> Reimagined into a visual novel style video game


## **Game Background**
A robot named "H-3lP" needs your help defeating the detected bugs inside his mainframe!



Crush the bugs by answering python-based questions correctly. 
But whatch out! 

Get a question wrong and you lose some health! If you lose too much health, 
the mainframe is taken over by the bugs and it's game over...
